# EspGauges project.  Written in c++.

## 1. Hardware used:

- Waveshare ESP32-S3-LCD-3.16 https://www.waveshare.com/wiki/ESP32-S3-LCD-3.16

## 2. Software used:

- PlatformIO inside vscode for developement https://github.com/platformio
- LovyanGFX as a display driver https://github.com/lovyan03/LovyanGFX
- LVGL for making the UI https://github.com/lvgl/lvgl
- Simhub for telemetry data https://github.com/SHWotever/SimHub

## 3. Goal:

- Provide a smooth and clean looking gauge for racing games supported by simhub, while keeping good performance.
